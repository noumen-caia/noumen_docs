## Введение

Расширения — это дополнение, созданные сообществом для расширения функциональности. Каждое расширение может выполнять одно или несколько действий в рабочем пространстве: от простых команд до сложных интеграций с визуальным редактором нод.

В этой документации описывается:

- Как создать, запустить и опубликовать расширение
- Как воспользоваться SDK для расширений

### Что могут делать расширения?

Вот несколько примеров возможностей расширений:

- Изменить внешний вид с помощью цветовых тем
- Добавить пользовательский интерфейс
- Создать собственные команды и палитры
- Работать с файловой системой
- Интегрироваться с редактором нод

Более полный обзор API расширений можно найти на странице [«Возможности расширений»](./capabilities.md)

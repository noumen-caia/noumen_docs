# Точки вклада (Contribution Points)

Точки вклада — это набор JSON-объявлений, которые вы делаете в поле `contributes` манифеста расширения `package.json`. Ваше расширение регистрирует точки вклада для расширения различных функций.

Ниже представлен список всех доступных точек вклада:

## Команды (commands)
Добавление пользовательских команд в палитру команд - [Подробнее](../guides/command.md)

## Конфигурация (configuration)
Добавление настроек расширения - [Подробнее](../guides/configuration.md)

## Сочетания клавиш (keybindings)
Назначение пользовательских сочетаний клавиш - [Подробнее](../guides/keybindings.md)

## Нотации (notation)
Определение правил отображения проектов - [Подробнее](../guides/notation.md)

## Ноды (nodes)
Добавление библиотек пользовательских нод - [Подробнее](../guides/nodes.md)

## Темы (theme)
Создание цветовых тем интерфейса - [Подробнее](../guides/theme.md)

Каждая точка вклада имеет свой собственный формат конфигурации и требования. Подробные описания каждого типа точки вклада можно найти в соответствующих руководствах.

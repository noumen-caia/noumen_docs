# Сочетания клавиш

Сочетания клавиш связывают клавиатурные комбинации с командами.

## Публикация в манифесте

Чтобы сочетание клавиш было доступно пользователям, добавьте его в манифест расширения:

```json
{
  "contributes": {
    "keybindings": [
      {
        "key": "ctrl+h",
        "command": "myExtension.sayHello"
      }
    ]
  }
}
```

# Тестирование и публикация

## Тестирование расширения

При создании проекта с расширением вы можете тестировать его в реальном времени:
- Сохранение проекта (Cmd+S) автоматически перезапускает расширение
- Изменения применяются мгновенно без перезагрузки среды

## Публикация расширения

Чтобы сделать расширение доступным для других разработчиков:
1. Подготовьте расширение к публикации
2. Опубликуйте в маркетплейсе расширений
3. После проверки расширение станет доступно для установки
